# FormularFuchs

Zentrale GitHub-Pages-Seite für **FormularFuchs**.

FormularFuchs entwickelt kostenlose Formulare und praktische Helfer für Alltagssituationen, in denen Menschen sonst selbst improvisieren müssen.

## Grundsätze

- kostenlos nutzbar
- ohne Registrierung
- möglichst lokale Verarbeitung im Browser
- keine kostenpflichtige Cloud für die Kernfunktionen
- verständliche Sprache
- keine versteckten Abos
- keine Behauptung einer garantierten rechtlichen Beweiskraft
